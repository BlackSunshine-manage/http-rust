Краткое описание папок и директорий:
`dev-scripts` - описывается установка в bat файле для разработки llvm-tools-preview инструментария для метрик по юнит-тестированию. llvm-cov - это инструмент Rust, предназначенный для сбора, агрегации и обработки данных о покрытии кода (code coverage) из файлов .profraw и .gcda, генерируемых LLVM/GCC. Он преобразует эти данные в различные форматы отчетов (например, LCOV, cobertura, html) для анализа покрытия тестированием.
`src` - исходники кода
`tests` - тесты
`\target\llvm-cov\html` - генерация отчётов о тестировании от llvm-cov
